# Moiz-ur-Rehman Portfolio

A responsive developer portfolio built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `moiz-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html`: page structure and portfolio content
- `style.css`: responsive layout, dark/light theme, and visual styling
- `script.js`: mobile navigation, theme toggle, and project detail modals
- `assets/profile.png`: supplied profile portrait
- `assets/Moiz-ur-Rehman-CV.pdf`: supplied résumé

## Deploy
Upload the extracted folder to a GitHub repository and import that repository into Vercel, or drag the folder into Netlify Drop. No build command is required because this is a static website.

## Before publishing
- Check the phone number and email address.
- Add your GitHub and LinkedIn profile URLs if you want them shown.
- Add live project links or screenshots when available.
- The home address from the résumé has intentionally not been published.
